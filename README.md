# 별빛 항해

로그인 없이 **링크만 있으면** 친구들과 같이 노는 행성 게임입니다. 사계절 행성에서 시작해, 행성 보기에서 다른 행성으로 항해할 수 있어요.
멀티 버튼을 누르고 닉네임을 적은 뒤 방을 만들면, 초대 링크를 받은 친구가 닉네임만 적고 들어옵니다.

## 들어 있는 파일

| 파일 | 하는 일 |
| --- | --- |
| `public/index.html` | 게임 (18단계: 17단계 전부 + 새 이름 '별빛 항해' · 행성 항해 · 도시 행성 첫 모습) |
| `server.js` | 게임 페이지를 보여 주고, 방마다 서로의 위치 · 채팅 · 포즈 · 옷을 전하고, 행성마다 따로인 방 세계(누가 지은 집 · 밭 · 모닥불)와 동물이 놀란 순간을 들고 있는 서버 |
| `package.json` | 서버 실행 설정 (필요한 부품: `ws`) |

폴더 구조를 그대로 유지해야 합니다. `index.html`은 반드시 `public` 폴더 안에 있어야 해요.

> **예전 이름(사계절 행성)으로 올려 둔 경우:** 18단계는 이름과 서버가 함께 바뀌었습니다. 아래 순서대로 새 저장소 `starlight-voyage`에 올리고 Render에서 새 서버를 여는 것을 권합니다.
> 하던 기록(보석 · 옷 · 가방 · 지은 것)은 기기에 **주소별로** 저장돼서, 새 주소에서는 처음부터 시작해요. 기록을 이어 가고 싶으면 예전 저장소에 네 파일을 모두 바꿔 올리면 됩니다(주소는 그대로, 게임 안 이름만 바뀜).

## 인터넷에 올리기 (Render 무료, 15분쯤)

### 1. GitHub에 파일 올리기

1. [github.com](https://github.com)에 가입하고 로그인합니다.
2. 오른쪽 위 **+** → **New repository**를 누릅니다.
3. 이름을 `starlight-voyage`로 적고 **Create repository**를 누릅니다.
4. 다음 화면에서 **uploading an existing file** 링크를 누릅니다.
5. 압축을 푼 폴더 안의 `server.js`, `package.json`, `README.md`, `public` 폴더를 한꺼번에 끌어다 놓습니다.
   (`public` 폴더째로 끌어야 `public/index.html` 구조가 유지됩니다.)
6. 아래 **Commit changes**를 누릅니다.

### 2. Render에서 서버 켜기

1. [render.com](https://render.com)에서 **GitHub 계정으로 가입**합니다.
2. 대시보드에서 **New** → **Web Service**를 누릅니다.
3. 방금 만든 `starlight-voyage` 저장소를 고르고, 서비스 이름도 `starlight-voyage`로 둡니다. 주소는 이 이름으로 정해져요.
   (목록에 없으면 GitHub 권한 설정에서 이 저장소 접근을 허용해 주세요.)
4. 설정을 이렇게 맞춥니다.
   - **Language**: `Node`
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Instance Type**: `Free`
5. **Deploy Web Service**를 누릅니다.
6. 몇 분 뒤 로그에 `별빛 항해 서버가 켜졌어요`가 보이고, 위쪽에 `https://starlight-voyage.onrender.com` 같은 주소가 생깁니다(같은 이름이 이미 있으면 뒤에 글자가 붙어요).
   **이 주소가 게임 링크입니다.**
7. 예전 사계절 행성 서비스는 Render에서 **Suspend**하거나 지워 두세요. 무료 사용 시간을 서비스끼리 나눠 쓰기 때문이에요. 친구들에게는 새 주소를 보내 주세요.

## 친구와 놀기

1. 게임 링크를 열고, 오른쪽 위 **멀티** 버튼(말풍선)을 누릅니다.
2. 닉네임을 적고 **방 만들기**를 누르면 4글자 방 코드가 생깁니다.
3. **초대하기**를 눌러 링크를 보냅니다. 공유 창(카카오톡 등)이 뜨거나, 공유 창이 없는 기기에서는 링크가 복사돼요.
4. 친구는 받은 링크를 열고 닉네임을 적은 뒤 **들어가기**를 누르면 끝입니다.
   방 코드만 알려 줘도 됩니다. 멀티 창에서 코드를 적고 들어가기를 누르면 돼요.

한 방에 **최대 8명**까지 들어올 수 있고, 방 안에서는 채팅, 같이 사진 찍기, 보석 레이스, 반응을 함께 할 수 있습니다.

## 행성 항해 (18단계)

위쪽 **행성 보기**를 누르면 화면 구석에 다른 행성이 떠 있습니다. 행성이나 그 이름표를 누르면 소개 카드가 뜨고, **○○ 행성으로 가기**를 누르면 별빛 터널을 지나 그 행성에 도착해요. 돌아올 때도 같은 방법입니다.

| 행성 | 지금 할 수 있는 것 |
| --- | --- |
| 사계절 행성 | 지금까지의 모든 것: 보석 · 채집 · 농사 · 낚시 · 모닥불 · 집 옷장 · 주민 부탁 · 레이스 |
| 도시 행성 | 18단계 첫 모습: 도시 구경 · 다리 건너기 · 주민 만나기 · 강에서 낚시 (코인 · 보물 상자 · 카트는 다음 단계) |
| 공룡 행성 | 19단계에 열려요 |

- 캐릭터 · 옷장의 옷 · 가방은 어느 행성에 가도 그대로입니다. 보석 · 주민 · 지은 것 · 부탁은 행성마다 따로예요.
- **같은 방이면 다른 행성에 있어도 채팅이 이어집니다.** 다른 행성의 친구는 보이지 않고, 멀티 창에 `준호 · 도시 행성에 있어요`와 **같이 가기** 버튼이 나와요.
- 방에 있는 채로 항해하면 도착한 행성에서 같은 방에 저절로 다시 들어갑니다. 초대 링크는 지금 있는 행성으로 열려요.

### 도시 행성 (첫 모습)

- **도심:** 별빛 광장(도착하는 곳)에서 큰길 8갈래가 뻗고, 별빛 타워와 빌딩숲이 둘러쌉니다.
- **강변:** 행성을 가로지르는 강에 다리 10개. 다리는 걸어서 건너고, 다리 위에서 낚시도 돼요.
- **공원:** 나무 우거진 언덕과 집, 벤치.
- **항구:** 컨테이너 · 크레인 · 등대와 바다.
- 주민 미래(시장) · 모모(탐정) · 하루(배달부) · 오션(선장)이 인사합니다. 보석 · 짓기 · 보석 레이스는 도시에는 없어요.

## 사계절 행성의 마을 생활

### 버튼과 키

| 버튼 | 키 | 하는 일 |
| --- | --- | --- |
| 할 일 (화면 아래 가운데) | `E` | 가까이 있는 것에 맞춰 바뀝니다: **나무하기 · 돌 캐기 · 풀 뜯기 · 꽃씨 받기 …**(모으기), **집에 들어가기**(집 문 앞), **씨앗 심기 · 물 주기 · 거두기**(밭 앞), **모닥불에 앉기**, **낚시하기**(물가를 바라볼 때) |
| 망치 (점프 위 두 번째) | `B` | 짓기: 집 · 텐트 · 밭 · 모닥불, 내가 지은 것 치우기 |
| 가방 (점프 바로 위) | `I` | 가진 것(먹을 것 · 씨앗 · 재료)과 주민 부탁 보기, 먹기 · 굽기 · 친구에게 주기 |
| 엎드리기 (점프 왼쪽) | `C` | 배를 땅에 대고 엎드립니다. 움직이면 천천히 기어가요. 점프 · 할 일 버튼(일어나기) · `C`로 일어나요 |
| 친구 찾기 (위쪽 나침반, 방에 친구가 있을 때) | | 켜면 화면 밖이나 멀리 있는 친구 쪽 가장자리에 화살표와 이름 · 거리가 나와요. 누르면 그 친구 쪽을 바라봐요 |

### 모으기

나무, 바위, 풀숲, 꽃 곁에 서면 할 일 버튼이 바뀝니다. 한 번 모은 자리는 잠시(1분 30초~2분 30초) 쉬었다가 다시 모을 수 있어요. 쉬는 시간은 사람마다 따로입니다.

| 곁에 설 것 | 버튼 | 얻는 것 |
| --- | --- | --- |
| 나무 (벚나무 · 활엽수 · 단풍나무 · 소나무) | 나무하기 | 나무 1~2 |
| 바위 | 돌 캐기 | 돌 1~2 |
| 풀숲 | 풀 뜯기 | 풀 1~2, 가끔 옥수수 씨앗 |
| 꽃밭 (봄 · 여름) | 꽃씨 받기 | 당근 씨앗 |
| 덤불 | 산딸기 따기 | 산딸기, 가끔 토마토 씨앗 |
| 해바라기 (여름) | 해바라기 씨 따기 | 해바라기 씨 2 |
| 호박 (가을) | 호박씨 받기 | 호박 씨앗 |
| 버섯 (가을) | 버섯 따기 | 버섯 |

### 짓기

재료가 있어야 짓고, **한 사람이 종류마다 하나씩** 지을 수 있습니다(집 하나, 텐트 하나, 밭 하나, 모닥불 하나).

| 짓는 것 | 재료 |
| --- | --- |
| 집 | 나무 8 · 돌 5 |
| 텐트 | 나무 3 · 풀 5 |
| 밭 | 나무 3 · 풀 2 |
| 모닥불 | 나무 3 · 돌 3 |

망치 버튼에 재료가 얼마나 모자란지 나옵니다. 고르면 앞에 반투명한 모양이 나타나요. 초록이면 지을 수 있고, 빨강이면 막대 위에 이유가 나옵니다(물 위 · 가파른 곳 · 나무나 바위 · 주민 곁 · 보석 자리 등).
**돌리기**(`R`), **색**(집 · 텐트), **짓기**, **취소**(`Esc`)를 누릅니다.

- 지은 것 위에는 누가 지었는지 남습니다. **치우기는 지은 사람만** 할 수 있고, 치우면 재료의 반을 돌려받아요.
- 주민이 서 있는 곳 가까이는 비워 둬야 합니다(이야기할 자리).
- 15단계에서 지은 것은 내 것이 됩니다. 방에 있던 주인 없는 옛것은 누구나 치울 수 있어요.

### 밭

밭에는 여섯 칸이 있습니다. 칸 앞에 서서 **씨앗**을 고르세요. 씨앗은 모으거나 주민 부탁으로 받습니다. 친구 밭에 심어도 내 씨앗을 씁니다.

| 작물 | 다 자라는 시간 |
| --- | --- |
| 당근 | 1분 |
| 토마토 | 1분 30초 |
| 옥수수 | 2분 |
| 호박 | 2분 30초 |

물을 주면 그때부터 두 배 빨리 자랍니다. 게임을 꺼 둔 동안에도 자라요.
다 자라면 할 일 버튼이 노랗게 되고, 거두면 가방에 들어갑니다. 거둘 때 절반쯤은 씨앗도 하나 나와요.

### 낚시

물가에서 물을 바라보면 **낚시하기**가 뜹니다.
찌가 쑥 들어가며 **당기기!**가 노랗게 깜빡이면 1초 안에 누르세요.
잡히는 물고기는 호수의 계절마다 다릅니다(봄 피라미 · 여름 붕어 · 가을 연어 · 겨울 빙어). 움직이면 낚싯대를 거둡니다.

### 먹기 · 굽기 · 나눠 주기

- 작물 · 산딸기 · 해바라기 씨는 바로 먹을 수 있고, 생선과 버섯은 모닥불 곁에서 **구워야** 먹을 수 있어요.
- 모닥불 곁에서 가방을 열면 **굽기**가 생겨요. 생선은 구운 생선, 채소와 버섯은 채소 꼬치가 됩니다.
- 먹으면 잠깐 **든든해져서** 더 빨리 달리고 더 높이 뜁니다(간식 15초, 작물 25초, 구운 것 60초).
- 친구가 6m 안에 있으면 **주기**가 생겨요. 씨앗과 재료도 줄 수 있습니다.

### 집 안 옷장 (꾸미기)

내 집이든 친구 집이든 문 앞에 서면 **집에 들어가기**가 뜹니다. 들어가면 아늑한 방과 옷장이 나와요(벽 색은 집 색을 따라갑니다).

| 옷장 칸 | 고를 수 있는 것 |
| --- | --- |
| 모자 | 비니, 밀짚모자, 야구모자, 벙거지, 곰돌이 모자, 왕관, 안 쓰기 |
| 머리 | 모양 7가지(짧은 머리 · 단발 · 긴 머리 · 양갈래 · 포니테일 · 똥머리 · 뾰족 머리) + 색 8가지. 뒷머리가 뒤통수를 다 덮어서 어떤 모자를 써도 비어 보이지 않아요 |
| 옷 | 모양(패딩 · 줄무늬 · 멜빵) + 색 8가지, 색 조합 7가지(비니 · 목도리 · 배낭 색과 '기본' 옷 색) |
| 신발 | 부츠, 장화, 운동화, 털부츠, 빨간 구두 |
| 가방 | 배낭, 곰돌이 가방, 요정 날개, 망토, 안 메기 |
| 꾸미개 | 꽃 핀, 동그란 안경, 리본, 별 머리띠, 그리고 보석으로 받은 선물(화관 · 선글라스 · 배지 · 귀마개)을 쓰고 벗기 |

- 바꾼 옷은 바로 저장되고, **같은 방 친구 화면에도 똑같이** 보입니다. 옷장에 들어가 본 적 없는 사람도 내 화면의 내 모습 그대로 친구에게 보여요.
- 처음 시작하는 사람은 저마다 다른 색 조합으로 시작합니다(16단계부터 하던 사람은 원래의 파란 '바다' 조합).
- 흐리게 보이는 옷은 잠겨 있어요. 아래에 적힌 주민의 부탁을 들어주면 풀립니다. 왕관은 네 계절 선물을 모두 모으면 풀려요.
- 집 안에 있는 동안 친구 화면에서는 내가 보이지 않습니다. **나가기**(`Esc`)를 누르면 문 앞으로 나와요.

### 주민 부탁

주민 이름표에 **!**가 떠 있으면 부탁이나 받을 것이 있다는 뜻입니다. 말을 걸면 부탁을 받고, 가방 위쪽에서 얼마나 했는지 볼 수 있어요. 다 하면 알림이 뜨니, 그 주민에게 다시 가서 말을 걸면 보상을 받습니다. 주민마다 부탁이 세 개씩 차례로 나와요.

| 주민 | 부탁 | 받는 것 |
| --- | --- | --- |
| 보미 (봄) | 꽃씨 두 개 받기 → 밭 만들기 → 작물 세 번 거두기 | 씨앗 · 풀, 꽃 핀 · 요정 날개 |
| 해솔 (여름) | 물고기 두 마리 → 모닥불에서 두 번 굽기 → 물고기 다섯 마리 더 | 씨앗 · 풀 · 돌 · 나무, 벙거지 · 장화 |
| 도토 (가을) | 나무 다섯 개 모으기 → 내 집 짓기 → 씨앗 네 번 심기 | 씨앗 · 돌, 멜빵 옷 |
| 설이 (겨울) | 모닥불 피우기 → 모닥불 앞 연주 → 옷 갈아입기 | 재료 · 씨앗, 곰돌이 모자 · 털부츠 · 망토 |

### 모닥불 캠핑

모닥불 곁에서 **모닥불에 앉기**를 누르면 불 앞에 앉고, 아래에 모닥불 막대가 나옵니다.

- **기타 치기**, **노래하기**, **곡 바꾸기**(모닥불 노래 · 별빛 왈츠), **가방**, **일어나기**가 있어요.
- 친구가 기타를 치고 있으면 노래는 그 곡과 박자에 맞춰 들어갑니다.
- 앉아 있을 때 같이 사진을 찍으면 **앉은 채로** 만세 포즈를 합니다.
- 소리가 안 나면 위쪽 소리 버튼이 켜져 있는지 확인해 주세요.

### 계절 동물

| 계절 | 땅 · 물 | 하늘 |
| --- | --- | --- |
| 봄 | 토끼, 오리 가족(엄마 뒤를 새끼 셋이 졸졸) | 파랑새 (빙빙 돌다 내려앉아 콕콕) |
| 여름 | 개구리(물가), 거북이(놀라면 웅크림) | 제비 (낮게 휙휙) |
| 가을 | 다람쥐(단풍나무 곁), 고슴도치(놀라면 웅크림) | 기러기 (V자로 행성을 한 바퀴) |
| 겨울 | 펭귄(놀라면 배로 미끄럼), 북극여우 | 흰멧새 |

호수마다 그 계절 물고기가 헤엄치고, 낚시찌를 던지면 가까운 물고기가 모여듭니다.
**같은 방이면 모두에게 동물이 똑같이 보입니다.** 누가 다가가 동물이 놀라면, 모든 친구 화면에서 같은 순간에 같은 쪽으로 달아나요.

### 날씨

계절마다 10분에 한 번꼴(8~12분 간격)로 궂은 날씨가 10~15초 동안 옵니다: 봄비, 여름 소나기(번개 · 천둥 두세 번), 가을 안개, 겨울 눈보라. 계절끼리는 2분 30초씩 어긋나 있어요.
**같은 방이면 날씨도 모두에게 똑같습니다.** 서버 시각으로 계산하므로 기기 시계가 틀려도 같은 때 비가 오고, 소나기 번개도 같은 순간에 칩니다(혼자 놀 때도 같은 규칙을 따라요).

---

### 친구 찾기

방에 친구가 있으면 위쪽 멀티 버튼 왼쪽에 나침반 버튼이 생깁니다. 켜 두면 화면 밖에 있거나 멀리(34m 넘게) 있는 친구마다 화면 가장자리에 화살표와 `이름 거리`(예: `민지 40m`)가 나와요. 집 안에 있는 친구는 `(집 안)`이라고 붙습니다.
표시를 누르면 내 캐릭터가 그 친구 쪽을 바라보니, 그대로 앞으로 걸어가면 만납니다. 가까워져 친구가 화면에 보이면 화살표 대신 원래 이름표가 보여요.

## 알아 둘 것

- **무료 서버는 잠을 잡니다.** 15분 동안 아무도 접속하지 않으면 멈추고, 다음에 누가 열면 깨어나는 데 1분쯤 걸립니다. 그동안 Render의 로딩 화면이 보여요. 누군가 방에서 놀고 있는 동안에는 잠들지 않습니다.
- **방 세계는 행성마다 따로입니다.** 사계절 행성에 지은 밭은 도시 행성에서는 보이지 않고, 다시 사계절 행성으로 오면 그대로 있어요.
- **방은 서버 메모리에만 있습니다.** 서버가 다시 켜지면 방이 사라지지만, 방에 있던 사람들은 자동으로 다시 연결되어 같은 코드의 방으로 모입니다. 아무도 없는 방은 30분 뒤 지워집니다.
- **방 세계(집 · 텐트 · 밭 · 모닥불)는 방을 만든 사람의 세계입니다.** 방을 만들면 혼자 지어 둔 것으로 시작하고, 방에서 누가 짓거나 심은 것은 방을 만든 사람 기기에 계속 저장됩니다.
  - 서버가 다시 켜져 방 세계가 사라져도, 방을 만든 사람이 다시 연결되면 자동으로 다시 올라갑니다(그사이 친구가 지은 것과 합쳐져요).
  - 다른 사람 방에서 놀다 나오면 내 원래 세계로 돌아옵니다.
- **보석, 선물, 기록장, 가방, 옷, 주민 부탁은 각자 기기에 저장됩니다.** 서버에는 방 세계 말고는 아무것도 남지 않아요.
- **지은 것의 주인은 기기(브라우저)로 구별합니다.** 브라우저 기록을 지우거나 다른 기기로 들어오면 다른 사람으로 보여서, 전에 지은 것을 치울 수 없어요.
- 연결이 끊기면 멀티 창에 `연결이 끊겼어요. 다시 잇는 중…`이 뜨고 알아서 다시 연결됩니다.

## 내 컴퓨터에서 먼저 해 보기 (선택)

1. [nodejs.org](https://nodejs.org)에서 Node.js(LTS)를 설치합니다.
2. 이 폴더에서 터미널을 열고 `npm install`, 그다음 `npm start`를 실행합니다.
3. 브라우저에서 `http://localhost:3000`을 엽니다.
   같은 와이파이의 휴대폰에서는 `http://컴퓨터IP:3000`으로 들어올 수 있어요.
   (방화벽이 막으면 허용해 주세요. https가 아닌 이런 주소에서는 초대하기를 누르면 공유 대신 주소가 글자로 보여요.)
